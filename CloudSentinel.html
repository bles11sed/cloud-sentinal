Module 1: Log ingestion and normalisation

Three raw log formats arrive as text. Each line is parsed into one common event schema (time, user, IP, country, action, resource, status, bytes). Select a row to compare the raw line with its normalised form, or paste your own logs below.

Module 2: Threat detection engine

Each normalised event runs through rule checks on sliding time windows, plus a statistical check that compares a user's call rate with their own baseline. Change a threshold and the next events use it.

Attack lab each attack uses a fixed attacker IP, so blocking it has a visible effect on the next run

Module 3: Alerts and automated response

Alerts are scored, de-duplicated and tracked from open to resolved. Respond by blocking an IP, disabling a user or applying the fix. Turn on the playbook to answer critical alerts automatically.
